# Setup Toolkit

> [!NOTE]
> Guías/scripts de configuración para sistemas Linux.

## Qué incluye

- Guías paso a paso para instalación y configuración.
- Scripts de automatización.
- Ajustes de herramientas y terminal.

## Estructura

- [Debian/](Debian/): documentación y scripts relacionados con Debian.
  - [Debian/Ubuntu/Powerline/](Debian/Ubuntu/Powerline/): configuración de Powerline.
  - Script de eliminación de snaps: [Debian/Ubuntu/snapRemove.sh](Debian/Ubuntu/snapRemove.sh)
- [Docker/](Docker/): guía de instalación y configuración.
- [CiscoPT/](CiscoPT/): instalación de Cisco Packet Tracer.
- [Matlab/](Matlab/): notas de instalación/configuración de MATLAB.
- [Quartus/](Quartus/): guía para Quartus Lite.
- [virtualbox/](virtualbox/): guía para VirtualBox.

## Uso rápido

1. Abre la carpeta que corresponda a tu sistema.
2. Sigue el README específico.
3. Si existe un script `setup.sh`, ejecútalo con permisos de administrador.

## Alcance

Este repositorio no sustituye la documentación oficial, es un apoyo.
